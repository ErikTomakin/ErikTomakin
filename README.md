## How I Build

- React Native + Expo — single codebase, iOS + Android
- Local-first architecture — expo-sqlite, nothing on a server by default
- AI via Claude API through a Cloudflare Worker relay — keys never in the binary
- Proven patterns reused across every app: ephemeral photo pipeline, two-stage AI verification, RevenueCat IAP, SQLite schema versioning
