How to Get Started
1
Open the link above and click Make a copy. The template saves to your Google Drive.
2
Run Full Setup: Click the Expense Tracker menu → ★ Full Setup (one click). This builds all 7 tabs in about 30–60 seconds.
3
Add your income sources on the Setup tab — e.g. DoorDash, Uber, Etsy. Then set your expense categories.
4
Start tracking! Use the Dashboard or Mobile Entry tab to log transactions. The Reports tab updates automatically.
5
Use AI Prompts on the last tab — copy a prompt, paste it into ChatGPT or Claude with your data for instant tax insights. No API needed.
Quick Tips
  • The IRS mileage rate updates automatically — check the Setup tab each January.
  • Log expenses as negative amounts (e.g. −$45.00 for fuel).
  • Use Expense Tracker → Clear All Transactions to reset at year-end.
  • Print the Instructions tab: File → Print → Portrait → Fit to page width.
